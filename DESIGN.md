# Design Specification: Price History Extension

## Aesthetic: Modern Utility
An immersive micro-extension of the `pricehistory.id` ecosystem. Clean, trustworthy, and atmospheric.

## Core Dimensions

### 1. Tone & Mood
**Modern Utility**: High-end tool feel. Fast, precise, and visually aligned with the parent platform.

### 2. Color Palette
- **Primary Gradient**: `linear-gradient(135deg, #2FA252 0%, #52A8C9 100%)` (Emerald to Teal)
- **Background**: White (`#FFFFFF`) for content cards; Light Gray (`#F9FAFB`) for secondary surfaces.
- **Accents**: 
  - Emerald Green: `#2FA252` (Success, Primary actions)
  - Dark Slate: `#1F2937` (Primary text)
  - Medium Gray: `#6B7280` (Secondary text)

### 3. Typography
- **Headings**: *Plus Jakarta Sans* (Geometric, bold character)
- **Body & Data**: *Outfit* (High readability, clean geometric terminals)
- **Scale**:
  - H1: 18px / 1.2 (Popup title)
  - H2: 14px / 1.4 (Section headers)
  - Body: 12px / 1.5 (Default text)
  - Small: 10px / 1.5 (Metadata, captions)

### 4. Motion & Interaction
- **Hover**: `scale(1.02)` + `box-shadow` increase on cards and buttons.
- **Transitions**: `200ms ease-in-out` for all opacity and transform changes.
- **Loading**: Pulse animation on shimmer grounds for data-heavy sections.

### 5. Spatial Composition
- **Grid**: 4px base unit. 
- **Padding**: 12px or 16px standard.
- **Radius**: `12px` for main cards; `8px` for buttons and inputs.
- **Alignment**: Structured, symmetric vertical stack.

### 6. Backgrounds & Texture
- **Ground**: Brand linear gradient ground.
- **Cards**: Crisp white cards with soft, large-radius shadows (`box-shadow: 0 10px 25px -5px rgba(0, 0, 0, 0.1)`).

### 7. Differentiation
**Ecosystem Portal**: High-visibility link to the main dashboard that feels like a native integration.
